## What's new in v26.3 (September 15, 2026)
- Dappled forest: poplar trees, red shrubs, shelf mushrooms
- Abandoned camps with camp maps and explorer maps
- Wool and concrete stairs and slabs (16 colors)
- Cushions and single-use straw beds that skip the night without moving spawn
- VSync and server resource-pack option fixes from RC3

## How to use
1. Download v26.3.
2. Extract `Minecraft-Free-Java-Edition.zip`.
3. Run the minecraft launcher.
4. Pick Java Edition 26.3. Play.
