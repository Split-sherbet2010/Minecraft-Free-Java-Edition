## 🔧 Troubleshooting

**"Java is not found" error?**
- Install Java from [java.com](https://www.java.com) — free and takes 2 minutes.
- Or use the included `java` folder in the package (we bundle a portable JRE).

**Game won’t launch?**
- Right-click the launcher and select **"Run as administrator"**.
- Disable your antivirus temporarily (some flags free software).
- Ensure you extracted the files completely — don’t run from inside a zip.

**Black screen after launch?**
- Update your graphics drivers.
- Lower your in-game render distance.
- Press `F3` + `D` to clear loaded chunks.

**Multiplayer not connecting?**
- Check your firewall — allow Java through.
- Verify the server IP is correct and the server is online.
- Try a different server to rule out local issues.

**Download won’t start?**
- Use Chrome or Edge (some browsers block GitHub downloads).
- Disable VPN if you have one.
- Try the mirror link at the bottom of this page.
